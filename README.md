Sistema de API para criação automática de salas de Free Fire, com integração AutoGo.

Utilizado por diversas organizações (ORGs), agora com o código-fonte da API totalmente gratuito e disponível para a comunidade.

Importante: este repositório disponibiliza exclusivamente o backend/API. O desenvolvimento do painel administrativo e da interface fica por conta de cada organização.
